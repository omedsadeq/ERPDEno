# خزمەتگوزاری پەنجەمۆر — Lezan fingerprint sync

پەنجەمۆرەکان ڕاستەوخۆ لە ئامێری ZKTeco وە (`192.168.1.201`) دەخوێنێتەوە و دەیانخاتە
ناو بەشی **سەرچاوە مرۆییەکان** ی لێزان.

```
ئامێر ──ڕاستەوخۆ──▶ ڕیزی ناوخۆیی (queue.sqlite3) ──▶ داتابەیسی لێزان (hr_punches)
```

- **ڕاستەوخۆ:** هەر کاتێک کەسێک پەنجە دادەنێت، لە ماوەی یەک دوو چرکەدا لە لێزان دەردەکەوێت.
- **هیچ شتێک ون نابێت:**
  - هەر پەنجەمۆرێک سەرەتا لە فایلی `queue.sqlite3` لەسەر دیسک هەڵدەگیرێت.
  - ئەگەر ئامێر یان تۆڕ پچڕا، ئامێرەکە خۆی پەنجەمۆرەکان هەڵدەگرێت. کاتێک پەیوەندی گەڕایەوە، هەموویان دەخوێنرێنەوە.
  - ئەگەر داتابەیسی لێزان کار نەکات، پەنجەمۆرەکان لە ڕیزەکەدا دەمێننەوە تا دەگەڕێتەوە.
- **هەمیشە کار دەکات:** لەگەڵ هەڵبوونی کۆمپیوتەر خۆی دەست پێدەکات. هەر 5 خولەک جارێک پشکنین دەکرێت و ئەگەر ڕاوەستابوو دووبارە دەست پێدەکاتەوە.

## هاتن یان ڕۆیشتن؟
ئامێرەکە هەموو پەنجەمۆرێک وەک «هاتن» تۆمار دەکات، بۆیە **ڕیزبەندی** بڕیار دەدات:

- لە ناو یەک ڕۆژی کاردا (08:00 ی بەیانی تا 08:00 ی بەیانی دواتر)، پەنجەمۆری یەکەم **هاتن** ـە، دووەم **ڕۆیشتن**، سێیەم **هاتن**، و بەم شێوەیە.
- دوو پەنجەمۆر لە ماوەی **60 چرکە** ـدا وەک یەک دەژمێردرێن.
- ئەگەر هەڵەیەک هەبوو، لە لێزان لە پەنجەرەی ڕۆژ بە کرتەیەک چاک دەبێتەوە («گۆڕین بۆ ڕۆیشتن»).

## دامەزراندن (یەک جار، لەسەر کۆمپیوتەری سەنتەر)
1. ئەگەر پێویست بوو، `config.ini` بکەرەوە و IP ی ئامێرەکە ڕاست بکەرەوە.
2. کرتەی ڕاست لەسەر **install.bat** بکە و **Run as administrator** هەڵبژێرە.
   - ئەگەر Python نەبوو، خۆی بە `winget` **Python 3.12** دادەمەزرێنێت. ئەگەر نەیتوانی، لە https://www.python.org/downloads/ دایبمەزرێنە و **Add python.exe to PATH** دیاری بکە.
   - Python ی Microsoft Store بەکارنایەت، چونکە ناتوانێت لە پاشبنەمادا کار بکات.
   - پێویستییەکان دادەمەزرێنێت.
   - پەیوەندی ئامێر و داتابەیس تاقی دەکاتەوە.
   - پێش دەستپێکردن پرسیار دەکات (Y/N).
   - خزمەتگوزارییەکە دەست پێدەکات.
3. لە لێزان بڕۆ بۆ **سەرچاوە مرۆییەکان ← داشبۆرد**. کارتی ئامێرەکە دەبێت سەوز بێت: «پەیوەستە — ڕاستەوخۆ».

## گواستنەوە بۆ کۆمپیوتەرێکی تر
**لەسەر کۆمپیوتەری کۆن:** کرتەی ڕاست لەسەر **uninstall.bat** ← **Run as administrator**، بۆ ئەوەی دوو کۆمپیوتەر پێکەوە ئامێرەکە نەخوێننەوە.

**لەسەر کۆمپیوتەری نوێ:**
1. فۆڵدەری لێزان کۆپی بکە.
2. لە CMD بنووسە `ping 192.168.1.201`. دەبێت وەڵام بداتەوە. ئەگەر وەڵامی نەدایەوە، ئەم کۆمپیوتەرە لەسەر تۆڕی ئامێرەکە نییە، یان IP ـەکە لە `config.ini` ڕاست بکەرەوە.
3. **کات و ڕێکەوت و Time zone** ی ویندۆز ڕاست بکە (Baghdad, UTC+3)، چونکە کاتژمێری ئامێرەکە بە کاتژمێری ئەم کۆمپیوتەرە ڕاست دەکرێتەوە.
4. MySQL دەبێت لەگەڵ کۆمپیوتەر هەڵبێت. لە XAMPP Control Panel (Run as administrator)، لە ستوونی **Service** ی ڕیزی MySQL ـدا خانەکە دیاری بکە.
5. جارێک لێزان لە وێبگەڕ بکەرەوە، بۆ ئەوەی migration ـەکان خشتەکان دروست بکەن.
6. کرتەی ڕاست لەسەر **install.bat** ← **Run as administrator**. یەکەم جار ئینتەرنێتی پێویستە. ئەگەر `.venv` ـێک لە کۆمپیوتەری کۆنەوە هاتبێت، خۆی یەکێکی نوێ دروست دەکات.
7. کارتی ئامێرەکە لە داشبۆرد دەبێت سەوز بێت.

پێویست ناکات خەمی پەنجەمۆرەکان بخۆیت: ئامێرەکە هەموویانی لای خۆی هەڵگرتووە، و ئەوانەی دوای `start_from` ـن خۆیان دێنەوە (**تۆماری ئامێرەکە مەسڕەوە**). بەڵام ئەو گۆڕانکارییانەی بە دەست لە داتابەیسی کۆمپیوتەری کۆن کراون، تەنها کاتێک دێن کە داتابەیسەکەش بگوازیتەوە.

ئەگەر هەمان کۆمپیوتەر بوو و تەنها فۆڵدەرەکەت گواستەوە بۆ شوێنێکی تر، **install.bat** دووبارە لێبدەرەوە.

## فایلەکان
| فایل | کار |
|---|---|
| `install.bat` | دامەزراندن و دەستپێکردن (Run as administrator) |
| `status.bat` | ئایا کار دەکات؟ پشکنینی ئامێر و داتابەیس و دوایین دێڕەکانی لۆگ |
| `run-console.bat` | لە پەنجەرەیەکدا کار دەکات بۆ ئەوەی ببینیت چی دەکات (Ctrl+C بۆ وەستاندن) |
| `uninstall.bat` | وەستاندن و لابردن |
| `config.ini` | ڕێکخستنەکان: IP، پۆرت، ڕێکەوتی دەستپێک، کاتژمێر… |
| `logs/sync.log` | تۆماری هەموو کارەکانی |

## ڕێکخستنە گرنگەکانی config.ini
| ڕێکخستن | واتا |
|---|---|
| `ip`, `port` | ناونیشانی ئامێرەکە (`192.168.1.201`، `4370`) |
| `sync_time = yes` | ئەگەر کاتژمێری ئامێرەکە زیاتر لە یەک خولەک هەڵە بوو، بە کاتژمێری کۆمپیوتەر ڕاست دەکرێتەوە |
| `start_from` | پەنجەمۆری پێش ئەم ڕێکەوتە وەرناگیرێت. پەنجەمۆرەکانی Panjamor تا 2026-09-30 هێنراون |
| `double_press_seconds` | دوو پەنجەمۆر لەم ماوەیەدا وەک یەک دەژمێردرێن |

### گۆڕینی IP ی ئامێر
1. IP ی ئامێرەکە لەسەر خودی ئامێرەکە ببینە: **Menu ← Comm. ← Ethernet**.
2. لە CMD بنووسە `ping` و IP ـەکە، بۆ نموونە `ping 192.168.3.201`. دەبێت وەڵام بداتەوە.
3. `config.ini` بە Notepad بکەرەوە، `ip = …` بگۆڕە و پاشەکەوتی بکە.
4. **install.bat** دووبارە لێبدەرەوە (Run as administrator). خزمەتگوزارییەکە ڕادەگرێت و بە IP ی نوێ دەستی پێدەکاتەوە.

کارتی IP ی کۆن خۆی لە داشبۆرد لادەچێت.

## بەکارهێنەرانی ئامێر و PIN ی ناناسراو
خزمەتگوزارییەکە لیستی کەسەکانی سەر ئامێرەکەش (PIN + ناو) دەنێرێت بۆ لێزان. لە
**سەرچاوە مرۆییەکان ← کارمەندان ← بەکارهێنەرانی ئامێر**:
- **لەسەر ئامێرە، لە لێزان نییە:** بە یەک کرتە زیادی بکە بە ناوەکەی سەر ئامێرەکە، یان **ببەستەوە** بە کارمەندێکی هەبوو (ناوی هاوشێوە پێشنیار دەکرێت). پەنجەمۆرە چاوەڕێکراوەکانی خۆیان دێن.
- **بەستراو:** PIN ـی سەر ئامێرەکە و کارمەندەکەی لێزان پیشان دەدات.
- **لەسەر ئامێر نین:** ئەو کارمەندانەی پێویستە لەسەر ئامێرەکە تۆمار بکرێن.

هەر کارمەندێک **PIN ی ئامێر** ی خۆی هەیە (لە فۆرمی کارمەند دەگۆڕدرێت). ئەگەر کەسێک لەسەر ئامێر بە ژمارەیەکی تر تۆمار کرابێت، تەنها ئەو PIN ـە بگۆڕە. پەنجەمۆرە کۆنەکانی لای خۆی دەمێننەوە.

## داتابەیس
بە شێوەی بنەڕەت هەمان داتابەیسی لێزان بەکاردێت: `.env` ی لێزان، یان `localhost / leza / root`. پێویست بە ڕێکخستن ناکات.
